# 1단계 배포 안내 (v18.0)

HTML(v18.0)과 서버(`gas/Code.gs` v2)는 **함께** 바꿔야 합니다. 한쪽만 바뀌면 저장이 실패합니다.
4번과 5번은 연달아 진행하세요.

1. **백업**: GitHub 저장소 → Code → Download ZIP (지금까지의 기록·PDF 전체)
2. **서버 코드 교체**: 구글시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용을 전부 지우고 이 저장소의 `gas/Code.gs`로 바꾼 뒤 저장
3. **초기 설정**: 시트를 새로고침 → 상단 메뉴 `보건관리 시스템` → `① 초기 설정`
   - 권한 승인 창이 뜨면 허용 (드라이브 폴더 생성에 필요)
   - 관리자 비밀번호(8자 이상) 설정
   - `부서인증` 시트에 부서별 PIN 입력, 사용을 `Y`로 변경 (부서 이름은 `직원목록` 시트와 같게)
   - 안내 창에 나온 드라이브 폴더에 ZIP 안의 `records`, `교육일지`, `보호구`, `화학물질` 폴더를 그대로 업로드
   - `부서인증` 시트의 **부서장 이메일** 열에 부서장 메일 주소 입력 (신규입사 알림 수신)
   - `관리자설정` 시트에 자동으로 생긴 값 확인: `앱주소`, `보건관리자이메일`(회신 알림 수신), `신규입사기준일수`(7), `재알림간격일`(3)
   - 시트 메뉴 `④ 인사 사이트(Firebase) 연결·자동 로그인 설정`
     · 1/5: 휴직자관리 페이지 소스에서 `firebaseConfig = { apiKey: ..., projectId: ..., databaseURL: ... }` 부분을 복사해 붙여넣기
     · 2/5: 데이터 종류 `firestore` 또는 `rtdb` (페이지 코드에 `firestore()`가 있으면 firestore, `database()`면 rtdb)
     · 3/5: 직원 데이터 위치 (페이지 코드의 `collection('…')` 또는 `ref('…')` 안의 이름)
     · 4/5, 5/5: 자동 로그인 아이디·비밀번호 (스크립트 속성에만 저장)
     · 저장 직후 시험 조회 결과가 표시됩니다. "이름 열을 찾지 못했습니다"가 나오면 표시된 열 목록을 Claude에게 알려주세요
   - 시트 메뉴 `⑤ 매일 아침 자동 확인 켜기` (자동 로그인 → 직원정보 갱신 → 신규입사 알림·재알림. 자동 로그인이 안 되면 아무 메일도 보내지 않음)
4. **서버 배포**: Apps Script → 배포 → 배포 관리 → 기존 웹 앱 ✏ 수정 → 버전: `새 버전` → 배포
   - 반드시 **기존 배포를 수정**하세요 (새 배포를 만들면 URL이 바뀝니다)
   - 실행 사용자: 나 / 액세스 권한: 모든 사용자
5. **화면 반영**: `stage1-server-auth` 브랜치를 main에 합치기 (Claude에게 "main에 반영해줘")
6. **각 PC 첫 로그인**: 부서 PC는 부서 PIN으로, 보건관리자 PC는 관리자 모드로 한 번씩 로그인
   - 그 PC에만 남아 있던 기록이 자동으로 서버에 합쳐집니다
7. **토큰 폐기**: 모든 PC 병합이 끝나면 GitHub → Settings → Developer settings → Personal access tokens에서 기존 토큰 삭제
8. **GitHub 정리** (나중에): 기록·PDF가 git 이력에 남아 있으므로, 화면용 HTML만 있는 새 저장소로 옮기기

## 직원정보 업데이트 (관리자 모드 > 👥 직원정보관리)
- 엑셀에서 제목 줄까지 복사 → 붙여넣기 → 미리보기 → 업데이트
- "전체 직원 명단"을 체크하면 명단에 없는 재직자를 퇴사로 표시합니다 (행은 지우지 않음, 교육기록 보존)
- 엑셀 붙여넣기·인사 사이트 수동 가져오기는 **메일을 보내지 않습니다**
- 신규입사 알림 메일은 **자동 로그인**(매일 아침 7시, 또는 [지금 자동 확인])일 때만 발송됩니다
  · 대상: 최근 7일(`신규입사기준일수`) 안에 입사한 화학물질 사용부서 직원
  · 교육 기한: 입사일로부터 3일 (메일·확인 창·관리자 표에 표시, 지나면 ⚠ 기한초과)
  · 회신이 없으면 `재알림간격일`(3일)마다 최대 3회 재알림
- 부서장: 메일 [확인하기] → 부서 PIN 로그인 → 예/아니오 → '예'면 MSDS 교육일지 화면에 그 직원이 대상자로 추가됨

## 문제가 생기면
- 시트 메뉴 `③ 모든 로그인 강제 해제`: 모든 기기 로그아웃
- 부서 PIN을 바꾸면 그 부서의 기존 로그인은 즉시 해제됩니다
- 되돌리기: Apps Script 배포 관리에서 이전 버전 선택 + main을 이전 커밋으로 되돌리기
