## 2. 글꼴
- `Pretendard` → `Nanum Gothic` → `Malgun Gothic` 순서
- 본문 14~15px · 칸 이름 15px 굵게 · 화면 제목 28px(굵기 800) · 홈 타일 제목 22px
- PDF(교육일지 · 수령증)는 `Malgun Gothic` 그대로 (출력 양식은 바꾸지 않음)

## 3. 로고 · 위쪽 메뉴
- 왼쪽 위: 부민병원 로고 이미지만 (글자 없음). 높이 PC 40px · 1180px 이하 36px · 휴대폰 30px. 이미지는 HTML 안에 들어 있어 따로 파일이 필요 없음
- 메뉴 이름: 홈 · MSDS 관리 · 교육일지 · 보호구 지급 · 화학물질 보고서 · AI 위험성평가
  - 로그인 전에는 교육일지 하나만 보임 (부서 로그인 후 부서에 맞는 일지로)
  - '관리자' 메뉴는 관리자로 로그인했을 때만 보임
- PC 메뉴에는 아이콘을 쓰지 않음 (휴대폰 아래 메뉴만 아이콘 + 짧은 이름)
- 선택된 메뉴: 글자 `#3F7518` + 아래 3px `#67AF28` 줄
- 오른쪽 버튼: **[부서 / 관리자 로그인]** 하나 (#67AF28, 흰 글자, 아이콘 없음)
- 이모지는 위쪽 메뉴 · 관리자 메뉴 · 제목에 쓰지 않음

## 4. 홈
- 타일 5개: MSDS 관리 · 교육일지 작성 · 보호구 지급 · 화학물질 보고서 · AI 위험성평가 ('관리자 모드' 타일 없음)
- **MSDS 관리만 색 채움**(#67AF28, 흰 글자). 나머지는 흰 바탕 + 단계색 테두리(PC 2px · 휴대폰 1px #67AF28)
- 나머지 타일은 마우스를 올리거나 누르면 테두리 색으로 채워지고, 로그인 전이면 로그인 창이 뜸
- 아래 두 칸: '부서 로그인하면 할 수 있는 일'(로그인 줄 없음) · '공지 · 업데이트'
- 칸 배치: PC 5칸 · 1180px 이하 3칸 · 휴대폰 2칸(MSDS 관리는 한 줄 전체)

## 5. 작성 화면 (교육일지 · 보호구 · 화학물질 · 위험성평가)
- 지금 화면 구성 그대로 + 색만 그린 계열. 위: 작은 위치 표시(예: 교육일지 › MSDS 교육일지) → 왼쪽 정렬 큰 제목 → 한 줄 설명
- 폭: 교육일지 · 보호구 · 화학물질 **1280px**, AI 위험성평가 **1200px**
- 단계 표시: 위 4px 막대(현재 · 지난 단계 #67AF28, 남은 단계 #DDDBD5) + 번호 동그라미(현재 #67AF28/흰 글자, 지난 #CFE5BA, 남은 #EEF6E6)
- 카드: 흰 바탕 · 테두리 `#E4E2DC` · 모서리 8px
- 한 줄에 칸 여러 개 + 버튼: 칸은 같은 너비, 버튼은 오른쪽 끝에 필요한 만큼(줄바꿈 없음). 날짜 칸은 날짜 선택(`type=date`), 최소 170px
- 버튼: 주요 = #67AF28 채움 · 보조 = 흰 바탕 + 회색 테두리 · 위험(반려 · 삭제) = 흰 바탕 + 빨강 글자. 높이 44~52px
