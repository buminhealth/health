# QI 발표 슬라이드 — 애플 스타일 디자인 기준 (감색)

발표 덱(`QI_경진대회_발표_애플.pptx`)을 만들거나 고칠 때 이 기준을 따릅니다.
16:9 (13.33 × 7.5in, 1280 × 720 격자 기준).

## 1. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#FFFFFF` | **모든 슬라이드 바탕 (예외 없음)** |
| 카드 | `#F5F5F7` | 카드 · 패널 채움 |
| 감색 (주색) | `#0A1F44` | 큰 숫자 강조 · 강조 카드 채움 · 현재 단계 · 번호 |
| 글자 | `#1D1D1F` | 제목 · 본문 |
| 보조 글자 | `#636366` | 부제 · 설명 · 각주 |
| 파랑 (보조 강조) | `#0066CC` | 화살표 · 작은 강조 1곳 |
| 회색 막대 | `#C7C7CC` | 차트의 '개선 전' |
| 감색 단계 | `#8FA6C9` · `#4F6A96` · `#2A4472` · `#0A1F44` | 간트 · 단계 구분 (Plan → Act 순) |
| 주황 | `#F56300` (막대) / `#B33F00` (글자) | '누락' 등 문제 지표에만 |
| 선 | `#E5E5EA` | 구분선 |

- 강조는 한 슬라이드에 감색 1곳 (+ 파랑 보조 1곳)까지. 그라디언트 · 그림자 금지.
- 감색 카드 위 글자: 흰색 `#FFFFFF`, 보조 `#A9B8D0`.

## 2. 글꼴

- 한글 `Noto Sans KR`, 숫자 · 영문 `Inter` (둘 다 Google Fonts 무료 — 발표 PC에 설치)
- 눈썹 라벨: 10pt · 굵게 · 감색 · 자간 넓게 (예: `PLAN · 주제 선정 배경`)
- 제목: 30pt · 굵게 · `#1D1D1F` · 한 줄 결론 문장
- 부제: 15pt · 보조 글자
- 본문: 14~16pt · 큰 숫자 40~60pt 굵게

## 3. 레이아웃

- 외곽 여백 64px. 제목은 모든 슬라이드에서 같은 위치.
- 오른쪽 위: PDCA 표시 `Plan Do Check Act` — 현재 단계만 감색 굵게 + 밑줄.
- 아래: 왼쪽 `부산부민병원 안전보건 통합관리 시스템`, 오른쪽 페이지 번호 (9pt 보조 글자). 띠 · 선 없음.
- 카드: `#F5F5F7` 채움 · 모서리 둥글게(약 20px) · 테두리 없음. 카드 사이 간격 16~20px.
- **이모지 금지. 아이콘은 쓰지 않는 것이 원칙** — 구분은 번호(01 · 02 · 03), 굵기, 감색 채움으로 한다. 꼭 필요할 때만 화살표(→) 정도.

## 4. 슬라이드 구성 (확정)

| # | 구성 |
|---|---|
| 1 | 왼쪽 제목 · 팀 / 오른쪽 결과 카드 3개 (−93% · 18→0건 · 94→0건) |
| 2 | 목차 — P · D · C · A 카드 4개 |
| 3 | 주제 선정 배경 — 3측면 카드(법·인증 / 현장 / ESG) + 감색 결론 바 |
| 4 | 팀 구성 — 팀원 카드 3개 + 1~10월 간트 |
| 5 | 현황 ① 누락 + 종이 100% — 월별 이행률(목표 100% 선) + 18건 · 100% 카드 |
| 6 | 현황 ② 행정시간 — 숫자 카드 3개 + 33분 48초 구성 막대(57·21·22%) |
| 7 | 지표 설정 · 목표 — 지표 카드 4개(기준값 → 목표, 근거 현황 장) + 측정 방법 3칸 |
| 8~ | 진행 중 |
