> 미리보기: `design/preview.html` (브라우저로 열기, 상단 버튼으로 7개 화면 전환)
> 상태: **승인됨 (2026-10-21)** — 홈페이지 색 · PIN 4자리 · 1·2차 먼저 · 휴대폰 하단 탭
> 색상: 부산부민병원 홈페이지 캡처(메인·로봇수술센터 페이지)에서 추출. 공식 CI 값이 따로 있으면 `:root` 토큰만 바꾸면 전체 반영.

## 설계 원칙 (사용자 → 기능 순서)

| 사용자 | 가장 급한 일 | 설계 결정 |
|---|---|---|
| 현장 직원 (간호사·미화·시설 등) | 노출 사고 시 **응급조치 확인** | 첫 화면 = 검색창. 로그인 없이 30초 안에 응급조치 |
| 부서장·책임간호사 | 신규입사자 확인, 교육일지 작성 | 로그인 후 첫 화면에 **"우리 부서 할 일"** (기한 순) |
| 보건관리자 | 결재, 누락·기한초과 관리 | 관리자 대시보드에 **숫자 4개 + 주의 목록** |

- 고령층·야간근무 고려: 본문 17px(모바일 16px), 최소 15px, 터치 영역 48px 이상, 명도 대비 4.5:1 이상(WCAG AA)
- 색만으로 상태를 구분하지 않음: 배지에 항상 글자("결재완료", "기한 D-1")
- 작성 화면은 **한 화면에 한 단계** (4단계 진행 표시), 작성 중 자동 저장

## Step 1. 화면 구조 = 결합안 (2026-10-21 3차 검토)

| | 현재 앱 | 2차안 (왼쪽 메뉴 프로그램형) | **결합안 (채택)** |
|---|---|---|---|
| 메뉴 | 위쪽 탭 한 줄 — 한눈에 보임 | 왼쪽 메뉴 묶음 — 한 단계 더 생각해야 함 | **위쪽 탭 유지**, 관리자 안에서만 왼쪽 메뉴 |
| 첫 화면 | MSDS 목록 + 상세 — 바로 사용 | 할 일 대시보드 — 로그인 전엔 빈 화면 | **MSDS 조회가 첫 화면** (로그인 없이) |
| MSDS | 목록 → 상세(그림문자·관리대상·성분·응급조치) | 표 + 오른쪽 작은 상세 | **현재 구조 그대로**, 응급조치를 성분 위로 |
| 작성 시작 | 상세의 [교육일지 작성] 버튼 | 메뉴 → 작성 | **상세 버튼 → PIN 창 → 물질이 들어간 작성 화면** |
| 할 일 | 없음 | 대시보드 | 로그인 후 **탭 아래 주황 띠** + [우리 부서] 탭 |
| 색 | 녹색·보라·검정 버튼 섞임, 이모지 아이콘 | 부민 그린 통일 | 부민 그린 통일, 버튼 3종(주요·보조·일반)만 |

```
┌ 상단 바 (진한 그린) ── [+] 부민병원 MSDS 통합관리 ●서버 연결됨 ───── 조회만 가능 · [부서 로그인] ┐
├ 탭: MSDS 조회 | 교육일지 | 보호구 지급수령증 | 화학물질 보고서 | 우리 부서 ③ ────────── 관리자 ┤
├ (로그인 후) ⚠ 61병동 할 일 3건 — 신규입사자 확인 D-1                              할 일 보기 → ┤
├ 목록 340px ─────────┬ 상세 ─────────────────────────────────────────────────────────────┤
│ [검색] [부서 선택]    │ 0.5N - Sodium Hydroxide                     [PDF 원본보기]          │
│ 전체 186종            │ OCI 주식회사 · 용도 장비세척                  [MSDS 교육일지 작성] ← 주요 │
│ ┌ 선택된 물질 ◇ ┐     │ 취급 부서: 진단검사의학과                     [특별교육일지 작성]      │
│ └──────────────┘     │ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│ ┌ 물질 ◇◇ ┐          │ ▌경고표지 및 관리대상: [위험] 그림문자 | 관리대상·특별관리·측정·특검 4칸 │
│ └─────────┘          │ ▌응급조치 요령 (피부·눈 / 흡입 / 먹었을 때 / 기타)                     │
│ …                    │ ▌구성성분 및 관리정보 (성분·CAS·함량·측정·특검)                        │
└──────────────────────┴────────────────────────────────────────────────────────────────┘
```

- 목록 카드에 **그림문자 작은 아이콘**을 붙여 위험 물질을 목록에서 바로 구분
- 작성 버튼을 누르면 PIN 창이 뜨고, 창 위에 **무엇을 작성하는지**(교육일지 종류 · 물질) 표시. 부서는 그 물질을 쓰는 부서가 먼저 나옴
- PIN 4자리 입력 → 바로 작성 화면, **고른 물질이 자동으로 들어감** (다시 찾지 않음)
- 처음 쓰는 사람: 오른쪽 아래 "3단계 안내" 1회 표시 (다시 보지 않기)
- 관리자: 메뉴가 많아 관리자 화면 안에서만 왼쪽 메뉴

### 휴대폰 (미리보기 ⑦)
- 상단: 검색창이 들어간 진한 그린 헤더 → 메뉴 6칸(3×2, 색 아이콘) → 할 일 → 응급
- **하단 탭 5개**: 홈 / MSDS / 교육일지 / 현황 / 내 부서 (엄지 닿는 위치, 휴대폰에서만)
- 물질 상세: **응급조치 → 보호구 → 구성성분 → 원문 PDF** 순 (긴급도 순)

## Step 2. 정보 구조도 (IA)

```
홈
├─ MSDS 관리 (로그인 불필요)
│   ├─ 물질 검색 ── 물질 상세 [응급조치 · 보호구 · 그림문자 · 구성성분 · 원문 PDF]
│   ├─ 부서별 사용 물질
│   └─ 응급조치 모음
├─ 교육일지 ──── [부서 PIN 로그인 팝업]
│   ├─ 특별안전보건교육일지 작성 (1 대상자 → 2 교육내용·사진 → 3 서명 → 4 확인·제출)
│   ├─ MSDS 교육일지 작성       (1 대상자 → 2 교육내용 → 3 서명 → 4 확인·제출)
│   └─ 우리 부서 제출현황 → 미리보기
├─ 보호구 지급 ── [부서 PIN 로그인 팝업]
│   ├─ 지급수령증 작성 (1 수령자 → 2 지급물품 → 3 서명 → 4 확인·제출)
│   └─ 우리 부서 제출현황
├─ 화학물질 보고서 ── [부서 PIN 로그인 팝업]
│   ├─ 신규사용 보고 / 사용중단 보고 (MSDS 첨부)
│   └─ 우리 부서 제출현황
├─ 우리 부서 (로그인 시 GNB에 표시)
│   ├─ 할 일 (신규입사 취급 확인 · 작성 필요 · 결재 대기)
│   └─ 제출현황 [교육일지 | 보호구 | 화학물질 보고서] 탭
└─ 관리자 모드 ── [관리자 비밀번호]
    ├─ 대시보드 (결재 대기 · 기한 초과 · 회신 대기 · 재직/휴직)
    ├─ 결재 관리
    ├─ 교육 현황 / 보호구 지급 / 화학물질 보고서
    ├─ 물질 마스터 점검 (v18.7: CAS 검증·법령대조표·빈칸 제안)
    ├─ 직원정보관리 (인사 사이트 가져오기 · 엑셀 · 부서 이름 점검)
    ├─ 신규입사 알림 (회신·미회신·기한초과)
    └─ 설정
```

- 깊이는 최대 3단계. 모든 작성 화면 상단에 **경로(브레드크럼)** + **진행 단계** 표시
- "제출현황"은 각 업무 메뉴 안과 "우리 부서" 두 곳에서 같은 화면으로 연결 (찾는 길이 두 개)

## Step 3. 로그인 UX (미리보기 ③)

**원칙: 보는 것은 로그인 없이, 쓰는 것은 PIN 4자리로.**

1. MSDS 검색·응급조치는 로그인 없음
2. 🔒 메뉴를 누르면 그 자리에서 **PIN 팝업** (페이지 이동 없음 → 로그인 후 원래 하려던 화면으로)
3. 부서 선택: **최근 사용 부서 4개를 큰 버튼**으로, 나머지는 검색 목록
4. PIN: **큰 숫자 키패드**(64px) + 점 4개 표시, **4자리를 누르면 자동 로그인** (확인 버튼 없음)
5. 12시간 유지, 오른쪽 위 칩에 "● 61병동"으로 상태 표시
6. 오류: "PIN이 맞지 않습니다 (남은 시도 4회)" → 5회 15분 잠금 → "보건관리실 내선 0000" 안내
7. 메일 [확인하기] 링크 → PIN 팝업 → 바로 해당 신규입사자 확인 창 (이미 구현된 흐름 유지)
8. 관리자: 같은 팝업에서 "관리자 로그인 →" 전환 (비밀번호 8자 이상)

> 현재 PIN은 4~6자리 허용 → **4자리로 통일**하면 자동 로그인이 가능 (시트 `부서인증` PIN만 4자리로 맞추면 됨)

## 적용 방법 제안 (결정 후)

현재 앱은 약 15,000줄 한 파일이고, 기능 로직(저장·결재·서명·동기화)이 화면과 섞여 있습니다.
**로직은 그대로 두고 겉모습을 단계적으로 바꾸는 방식**을 권합니다 (한 번에 갈아엎으면 회귀 위험이 큼).

1. **1차 (토큰·공통 스타일)**: 색·글꼴·버튼·카드·배지·표를 새 토큰으로 → 전 화면 분위기 변경 (기능 영향 거의 없음)
2. **2차 (메인·로그인)**: 앱 골격(상단 바 + 왼쪽 메뉴) · 오늘 할 일 화면 신설, PIN 팝업을 키패드형으로
3. **3차 (작성 화면)**: 교육일지·보호구·보고서를 단계형 레이아웃으로, 자동 저장
4. **4차 (관리자)**: 대시보드 신설, 사이드바 정리
- 각 단계마다 기존 시험(112개) + 명도 대비·글자 크기 자동 점검 + 화면 캡처 확인 후 배포

## 결정 사항 (2026-10-21 승인)
1. 색상: **홈페이지 색 그대로** (공식 CI가 나오면 `:root` 토큰만 교체)
2. PIN: **4자리 통일** → 4자리 입력 시 자동 로그인. `부서인증` 시트에서 4자리가 아닌 PIN을 미리 바꿔야 함
3. 적용 범위: **1·2차 먼저** (색·공통 스타일 + 메인 화면·PIN 키패드), 3·4차는 이후
4. 휴대폰 하단 탭: **도입** (PC는 상단 메뉴 유지)

## 검토에서 고친 것
- 모바일 퀵메뉴가 하늘색 헤더에 가려 아이콘이 잘리던 문제
- 메인(①) 휴대폰 화면을 ②와 같은 구조로 (3×2 타일 + 하단 탭)
- 명도 대비 4.5:1 미달 4곳: 파랑 배지, 관리자 개수 배지, 진행 단계 회색, 로고
- 15px 미만 글자 (배지·칩·안내문·하단 탭)
- 관리자 메뉴에 물질 마스터 점검 추가, 서버 v18.7 표시
- 하단 탭 "작성" → "교육일지"

## 2차 검토 (PC 프로그램형으로 변경)
- 요청: 큰 배너·타일의 홈페이지형이 업무 프로그램에 어울리지 않음 → 다른 업무 프로그램처럼 상단 바 + 왼쪽 메뉴 + 표 중심
- 적용: 상단 바 진한 그린, 선택 메뉴 연초록, 요약 카드 위 색 띠, 표 머리 고정, 오른쪽 상세 창, PIN은 창(모달)
- 자동 점검: 1920·1366·1100px × 8개 화면에서 명도 대비 4.5:1 미달 0건, 14px 미만 글자 0건, 가로 넘침 0건

## 3차 검토 (현재 앱 + 2차안 장점 결합)
- 요청: MSDS 조회는 현재 화면처럼 간단하게 — 목록 → 그림문자 상세 → [PDF 원본보기] / [교육일지 작성] → PIN
- 판단: 현장 직원(초보자)에겐 현재 앱의 "위쪽 탭 + 목록·상세"가 더 쉬움. 2차안의 장점(통일된 색, 할 일, 관리자 구조, 표)은 그대로 가져옴
- 자동 점검: 1920·1366·1100px × 7개 화면 명도 대비·글자 크기·가로 넘침 이상 없음
